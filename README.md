# Edu Learning Namibia

An [Expo](https://expo.dev) React Native project with [Expo Router](https://docs.expo.dev/router/introduction).

## Get Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npx expo start
   ```

Options to run the app:
- Press `a` to open on Android emulator/device
- Press `i` to open on iOS simulator
- Press `w` to open on web browser
- Scan the QR code with Expo Go on your mobile device

## Project Structure

- `app/` - File-based routing with Expo Router
  - `_layout.tsx` - Root stack layout
  - `index.tsx` - Entry screen
- `assets/` - Project images and app icons
