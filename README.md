# Edu Learning Namibia

A mobile study companion for Namibian learners, built with [Expo](https://expo.dev) (SDK 57) and [Expo Router](https://docs.expo.dev/router/introduction). Everything runs on the device: study content ships with the app and progress is saved locally with AsyncStorage.

The app offers two modes:

- **Learner**: pick a grade and subjects, then study lesson modules, practice quizzes, past papers, one-attempt competition quizzes, textbooks, and exam summaries. Opening a subject shows a Namibian "Did you know?" fact. XP and a daily streak track progress.
- **Explorer**: an OpenStreetMap map of Namibia's 14 regions. Each region lists places by topic (geography, culture, history, events, food, travel, safety).

## Get started

```bash
npm install
npx expo start
```

Press `a` for Android, `i` for iOS, `w` for web, or scan the QR code with Expo Go.

Other scripts:

```bash
npm run lint
npx tsc --noEmit
```

Builds use EAS (`eas.json` has `development`, `preview` and `production` profiles).

## Project structure

```
app/                       Screens (file-based routes, single Stack in _layout.tsx)
  index.tsx                Animated splash; routes to onboarding / choose-path / home / explore
  onboarding.tsx           3-step intro
  choose-path.tsx          Learner vs Explorer
  select-grade.tsx         Grade + subject picker (learner)
  home.tsx                 Learner dashboard (subjects + Explore map tab)
  subject.tsx              Subject hub: content, quizzes, textbooks, summaries
  topic-quizzes.tsx        Quiz list for a topic
  quiz.tsx                 Quiz player (resume, review, results)
  explore.tsx              Explorer-mode map
  region.tsx               Topic picker for a region
  region-topic.tsx         Places in a region for a topic
  region-site.tsx          Single place detail
components/
  OsmMapView.tsx           Leaflet map in a WebView, with offline fallback
  ExploreMapPane.tsx       Region search, markers and banner over the map
  ZoomableImage.tsx        Pinch / double-tap zoom image modal
constants/
  curriculum.ts            Grades and the 19 subjects
  subjectData.ts           Study content (full Physical Science set; template content for other subjects)
  subjectFacts.ts          "Did you know?" facts (subjectFactsData.json, generated by scripts/)
  quizProgress.ts          Per-subject quiz progress persistence
  learnerStats.ts          XP and daily streak (writes are serialized)
  namibiaRegions.ts        Region capitals and map camera helpers
  regionExplore.ts         Explore category labels (places load from the portal API)
  userPath.ts              Learner / explorer preference
scripts/                   Node scripts that generate the facts database
```

## Local storage keys

| Key | Purpose |
| --- | --- |
| `has_completed_onboarding`, `user_path` | Onboarding and chosen mode |
| `user_grade`, `user_subjects`, `has_selected_grade_and_subjects` | Learner curriculum choice |
| `learner_xp`, `learner_streak` | XP total and `{ count, lastDate }` streak |
| `quiz_progress_<subjectId>` | Quiz scores, answers and in-progress sessions |
| `subtopic_progress_<subjectId>` | Completed lessons |
| `saved_textbooks_<subjectId>` | Textbooks saved to the learner's library |
| `seen_facts_list_<subjectId>` | Facts already shown, so none repeat |

## Notes

- The map needs an internet connection: Leaflet loads from jsDelivr and tiles come from OpenStreetMap. When offline, the map shows a fallback message and region search still works.
- The schools leaderboard uses sample data until there is a backend. Only the learner's own XP is real.
